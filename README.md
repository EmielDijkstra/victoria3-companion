# Victoria 3 Companion

Een lokale overlay-app voor Victoria 3 die laat zien hoe je ervoor staat, waarschuwt voor problemen en
uitlegt waarom, zodat je het spel beter leert begrijpen. Werkt (straks) met ironman-saves en zonder het
spel aan te passen, dus achievements blijven behouden.

> Status: plan- en onderzoeksfase. Er is nog geen werkende app.

- Plan en inventarisatie: [`docs/plan.md`](docs/plan.md)
- Werkafspraken: [`CLAUDE.md`](CLAUDE.md) en [`CONTRIBUTING.md`](CONTRIBUTING.md)

Onofficiële fan-tool. Victoria 3 is © Paradox Interactive. Deze repo bevat geen spelbestanden of savegames.
