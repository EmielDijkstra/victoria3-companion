# Security

The app runs locally, reads your saves and game files read-only, and only contacts the internet when
you ask the optional AI advisor a question (Google Gemini, with your own key).

Found a security problem, for example a way for the app to write outside its own folder or to leak a
key? Please report it privately through GitHub: **Security → Report a vulnerability** on this
repository, instead of opening a public issue.

Never post your `GEMINI_API_KEY` or save files in an issue.
